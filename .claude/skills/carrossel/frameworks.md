# Frameworks de Copy — Referência Interna

Material pedagógico do PDF "O Código Escondido na Copy dos Carrosséis". Uso **interno** para escolher o ângulo narrativo dominante na Etapa 1 e calibrar Hook/Mecanismo na Etapa 3. **Não expor nomes de framework no output ao usuário.**

> Os exemplos do PDF original usam 2ª pessoa para fins didáticos. Nos outputs do agente, 2ª pessoa é proibida (ver `spec.md` §1).

---

## 1. Abertura Curiosa
**Psicológico:** Gatilho da Curiosidade + Abertura de Loop + Viés de Incompletude.
**Quando:** o leitor acha que já sabe sobre o tema; queremos mostrar nova camada. Insights contraintuitivos, reinterpretações, promessas escondidas.
**Mecânica:** abrir com pergunta/afirmação que quase entrega — mas não. Ativa loop mental.
**Erros:** ser genérico, entregar resposta cedo demais, perguntas batidas sem twist.

## 2. Autoridade
**Psicológico:** Autoridade + Prova Social Implícita + Validação Antecipada.
**Quando:** posicionar como referência. Frameworks, desmistificar erros, bastidores de resultados.
**Mecânica:** domínio técnico + storytelling de bastidor/conquistas práticas. Quanto mais específico (R$, número de carrosséis, mentorados), mais força.
**Erros:** números vagos, soar arrogante, chavões ("sou especialista em…").

## 3. Benefício Direto
**Psicológico:** Antecipação + Clareza + Economia Cognitiva.
**Quando:** entrega prática, acionável, transformadora (hacks, frameworks, ajustes rápidos).
**Mecânica:** funciona como headline de VSL. Foco em especificidade, tempo, facilidade aparente, contraste com a dor.
**Erros:** prometer genérico ("mais resultados"), não entregar, não ancorar transformação.

## 4. Pergunta Impactante
**Psicológico:** Disruptividade + Interrupção de Padrão + Autorreconhecimento.
**Quando:** gerar conflito interno, quebra de objeção, mudança de mentalidade, reeducação de público.
**Mecânica:** pergunta-espelho real, inesperada, incômoda — força o leitor a se posicionar.
**Erros:** perguntas óbvias ou fracas, tom professoral/agressivo, não entregar resposta à altura.

## 5. Testemunho Real
**Psicológico:** Prova Social + Autoridade Transferida + Validação Emocional.
**Quando:** validar método/estratégia/oferta. Mentoria, consultoria, treinamentos, serviços.
**Mecânica:** caso real com detalhes específicos, números críveis, conflito + virada.
**Erros:** resultados genéricos, esconder bastidor, focar só no número e esquecer a transformação humana.

## 6. Lista Valiosa
**Psicológico:** Escaneabilidade + Clareza de Valor + Antecipação por Volume.
**Quando:** hacks, insights práticos, mini tutoriais, correção de erros. Conteúdos altamente salváveis.
**Mecânica:** promessa no título + impacto prático em cada item. Números ímpares (3, 5, 7) tracionam mais.
**Erros:** tópicos repetitivos/óbvios, listar sem desenvolver, inflar número de itens sem substância.

## 7. Problema e Solução
**Psicológico:** Consciência de Dor + Alívio Emocional + Jornada de Transformação.
**Quando:** público sente dor recorrente sem entender a causa real; aquecer leads antes de oferta.
**Mecânica:** contraste emocional — começa no desconforto, termina no alívio. Não apressar a solução.
**Erros:** solução cedo demais, problemas genéricos, soluções óbvias ("poste com mais frequência").

## 8. Passo a Passo
**Psicológico:** Simplicidade + Microconquistas + Sensação de Controle.
**Quando:** frameworks, tutoriais, métodos exclusivos. Quando se quer alta percepção de valor + salvos.
**Mecânica:** processo claro em etapas lógicas. Cada passo gera clareza, motivação e leveza.
**Erros:** passos vagos ("defina seu objetivo"), linguagem técnica demais, falta de coesão entre passos.

## 9. Segredo Revelado
**Psicológico:** Exclusividade + Curiosidade Avançada + Transferência de Poder.
**Quando:** introduzir framework proprietário, bastidor de resultado, virada de chave, oferta de alto valor de forma indireta.
**Mecânica:** revelação real, específica, não óbvia. Quebra lógica comum / desmonta mito / mostra bastidor poderoso.
**Erros:** chamar de "segredo" algo trivial, revelar cedo demais sem tensão, autoajuda genérica.

## 5 Tipos de Abertura (Slide 1)

Material para calibrar o **Hook** na Etapa 3 e a **Linha 1 da Capa** na Etapa 2.

| Tipo | Função | Use quando |
|---|---|---|
| **Curiosidade** | Abrir loops, ativar lacuna de informação | Sacada nova, bastidor, segredo, quebra de padrão |
| **Provocação** | Quebrar padrões, gerar dissonância | Desafiar crença, expor erro comum, "não é possível" interno |
| **Autoridade** | Transferir credibilidade, baixar defesas | Experiência, dados reais, bastidores, provas de campo |
| **Identificação** | Empatia instantânea, espelhar dores | Atração emocional antes da lógica; conteúdos humanos/transformacionais |
| **Benefício Direto** | Mostrar ganho claro e específico de cara | Prometer concreto, ensinar método, transformar complexidade em solução |

## Mapeamento Framework → Ângulo Dominante (Etapa 1)

Tabela de apoio. **Nunca expor ao usuário.** Use para nomear o "Ângulo narrativo dominante" no formato Spec 5.3 (nome curto + tensão + mecanismo + ressalva).

| Framework | Sugestão de nome do ângulo (curto) | Tensão típica |
|---|---|---|
| Abertura Curiosa | "lacuna invisível" | quem acha que sabe ignora a camada que importa |
| Autoridade | "padrão observado" | repetição em volume revela mecânica que o caso isolado esconde |
| Benefício Direto | "ajuste pontual" | mudança mínima desbloqueia resultado desproporcional |
| Pergunta Impactante | "crença que não fecha conta" | a explicação consagrada não bate com o resultado real |
| Testemunho Real | "antes/depois com mecânica" | resultado isolado parece sorte; bastidor revela engenharia |
| Lista Valiosa | "microdecisões cumulativas" | o efeito não está em uma decisão, está na soma de pequenas |
| Problema e Solução | "causa deslocada" | o sintoma é onde se olha; a causa está fora do quadrante |
| Passo a Passo | "estrada pronta" | clareza de sequência reduz fricção de execução |
| Segredo Revelado | "regra interna do jogo" | há um padrão que separa amadores de profissionais |
